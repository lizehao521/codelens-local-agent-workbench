| 上游模型同步 (`modelSync`) | ❌ | ✅ | `MODEL_SOURCE_URL` | 按间隔拉取模型清单并落库 |

### 路径 / 接口错位点

1. **会话与 run 查询不是“无参列表”接口**：`GET /api/v1/sessions` 必须带 `X-Device-Token`，`GET /api/v1/runs` 必须带 `sessionId`。裸请求得到空列表或 `SESSION_REQUIRED`，不是服务未启动。
2. **数据库路径**：运行实例读 `AGENT_DB_PATH`（当前落盘为 `server/data/codelens.db`）；若启动目录/环境不同，会把“有数据”误判成“没有会话”。
3. **自定义上游**：客户端默认 `http://1.92.150.5:8787/v1`；适配器会归一化并拼 `/chat/completions`。当前该地址 TCP 不可达，NVIDIA 兜底返回 401，因此真实 LLM 端到端仍未验证。
4. **MCP**：`MCP_CONFIG_PATH` 为空，`mcp` 是 0 server、wired=false；不是连接器代码缺失，而是没有配置文件/服务器。
5. **试用模式**：`TRIAL_MODE_ENABLED` 未置 1；`trial` wired=true 但 enabled=false，兜底 Key/预算闸不会生效。
6. **可观测性与模型同步**：`OBSERVABILITY_ENABLED`、`MODEL_SOURCE_URL` 未配置；trace 表和模型同步代码已在，但没有写入/拉取。
7. **快照范围**：`CHECKPOINT_ENABLED=true`，但只覆盖 `fs.write`；`sys.exec`、MCP 工具的副作用不在快照范围，不能把“开启快照”理解成“所有副作用可回滚”。
8. **动态工具双路径**：任务义肢在 `tmp/tools/<sessionId>/`，晋升能力库在 `.codelens/tool-library/<sessionId>/`；清理闸只删前者，不应误删后者。
9. **自迭代账本**：任务规格在 `server/self-upgrade/tasks.json`，采纳账本在 `.self-upgrade/ledger.jsonl`，bridge 在 `.self-upgrade/loop/bridge/`；三者不是同一层，路径混用会造成“已采纳但未覆盖”的假象。

## 未验证 / 限制

- **真实 LLM 端到端**：自定义端点 TCP 不可达；NVIDIA 兜底 Key 401。Agent loop 的 fake-upstream 测试、45 次工具调用测试不能替代真实模型验证，故如实标为未验证。
- **MCP 实际连接**：当前 0 个 server，未做真实 MCP 连接/工具发现验证。
- **Observability / trial / modelSync 实际写入**：对应能力 disabled，仅有 wired/代码证据，未产生真实运行数据。
- **8080 端到端行为**：已验证 health、工具/供应商/能力目录、无 session 的 `SESSION_REQUIRED`；未验证真实模型生成与真实任务完成。

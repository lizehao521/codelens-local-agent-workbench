## 6. 已知风险与边界（别踩）

- **运行实例**：8080 上原来是 `dist/app.js` 的旧构建（17 个工具）。本轮已重建并重启到 2.20.0（19 个工具）。
  `check:tool-contract` 读的是**运行中的服务**，服务是旧构建时会报「注册表有、对外清单没有」的假红；
  不确定时用 `CODELENS_API=http://127.0.0.1:<port>` 指向新起的实例。
- **跨运行重派不带诊断**：`server/scripts/self-upgrade-loop.ts` 每次启动 `let feedback = ''`，
  只有同一次运行内的第 2/3 次尝试才带 `diag-*.txt`。跨运行重派时上一轮的诊断不会喂给 Agent。**未修。**
- **`maxIterations=25` 写死在派单 payload**：`AGENT_MAX_ITERATIONS` 改不动它。
- **吞吐在墙钟上，不在模型上**：实测 `deepseek-v4.1-flash` 两次都是 11–15 次调用、0 个文件；
  550B 慢但会写。把 `AGENT_TASK_BUDGET_MS` 从 1200000 抬到 2700000 后，G1 一次过（2058s）。
- **派单会留下大量本机产物**：`.self-upgrade/loop/` 下的 `sse-*.txt` / `diag-*.txt` / `fb-*.txt` / `checkpoints/`
  都是**本地证据**，未入库。别用宽 glob 把它们加进 `.gitignore` 去吞既有跟踪件。
- **`.env` 不入库**（`.gitignore:6`）。BYOK Key 只存浏览器，服务端不落库不记日志。
- **`acct-data/`** 是本机垃圾目录（只有一行 `acct`），未提交，可直接删。

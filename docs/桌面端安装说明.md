# CodeLens 桌面端安装说明（Windows）

CodeLens 桌面版是一个 Electron 应用，把前端页面与本地服务端打包进单个安装包，
装完即可在本机离线使用，无需额外安装 Node.js 或数据库。

## 一、产物信息

| 项目 | 值 |
| --- | --- |
| 安装包 | `CodeLens-Setup-2.0.0.exe`（仓库根目录下，可直接双击安装） |
| 大小 | 129,136,484 字节（约 123.2 MB） |
| SHA256 | `b0a99a17e1d6f3373ebd57e6d8ad57d59d50b2b9130f72e6e9706e53e68b13a9` |
| 版本 | 2.0.0 |
| 架构 | Windows x64 |
| 安装器类型 | NSIS（可选安装目录、非一键安装） |

> 本表对应 2026-10-30 的重建产物（修复卸载删数据 / 数据目录名错位 / 快捷方式残留）。

## 二、系统要求

- Windows 10 / Windows 11（x64）
- 磁盘空间：安装后约 377 MB（解压后），安装包本身 129,136,484 字节（约 123.2 MB）
- 无需管理员权限（默认按「当前用户」安装）
- 无需预装 Node.js / 数据库

## 三、安装步骤

1. **双击** `CodeLens-Setup-2.0.0.exe` 启动安装向导。
2. 若出现 Windows SmartScreen「Windows 已保护你的电脑」提示：
   点击 **更多信息** → **仍要运行**。
   （原因：本次构建未使用受信任的商业代码签名证书，详见「常见问题」。）
3. **欢迎界面**：点击「下一步」。
4. **许可协议**：阅读后选择「我接受」，点击「下一步」。
5. **选择安装位置**：
   - 默认路径：`%LOCALAPPDATA%\Programs\CodeLens`
     （形如 `C:\Users\<用户名>\AppData\Local\Programs\CodeLens`）
   - 可点击「浏览」改成其它目录（配置允许修改安装目录）。
   - 因为是「当前用户」安装，不需要管理员权限，也不会写入 `Program Files`。
6. **快捷方式**：默认勾选创建桌面快捷方式与开始菜单快捷方式（名称 `CodeLens`），
   可取消勾选后点击「下一步」。
7. 点击 **安装**，等待进度条走完（约 1–2 分钟，主要是解压 Electron 运行时）。
8. 点击 **完成**。可勾选「运行 CodeLens」立即启动。

## 四、安装后的目录结构

安装目录下（默认 `%LOCALAPPDATA%\Programs\CodeLens`）：

```
CodeLens.exe                 主程序（Electron 外壳）
resources/
  app.asar                   应用代码（主进程 main.cjs + 服务端 server-bundle.cjs）
  client/                    前端静态资源（由安装器释放）
  elevate.exe                提权辅助程序
```

## 五、数据存储位置（重要）

应用运行产生的数据**不放在安装目录**，而是放在当前用户的应用数据目录，
因此**升级或重装不会丢失数据**。

| 内容 | 路径 |
| --- | --- |
| 用户数据根目录 | `%APPDATA%\CodeLens` |
| 数据库 | `%APPDATA%\CodeLens\codelens.db` |
| MCP 服务器配置 | `%APPDATA%\CodeLens\config\` |
| 沙箱目录 | `%APPDATA%\CodeLens\sandbox\` |
| 审批密钥 | `%APPDATA%\CodeLens\approval-secret.key` |
| 日志 | `%APPDATA%\CodeLens\logs\` |

> 说明：MCP 配置必须放在可写目录，而 `app.asar` 是只读的，所以统一落在
> `userData/config` 下。

**备份/迁移**时，只需拷贝 `%APPDATA%\CodeLens` 整个目录。

> 从早期 2.0 安装包升级的用户注意：早期版本 `desktop/package.json` 未声明
> `productName`，Electron 用包名 `codelens-desktop` 当数据目录，数据实际落在
> `%APPDATA%\codelens-desktop`。新版启动时会把该目录下的数据库、审批密钥、
> MCP 配置与沙箱**一次性搬迁**到 `%APPDATA%\CodeLens`（新目录已有数据库时不搬迁、
> 不覆盖，旧目录保留可人工回滚）。

## 六、卸载

- 方式一：Windows「设置」→「应用」→ 找到 **CodeLens** → 卸载
- 方式二：安装目录下运行 `Uninstall CodeLens.exe`

卸载只删除程序文件，**不会删除 `%APPDATA%\CodeLens` 下的用户数据**
（`electron-builder.yml` 中 `deleteAppDataOnUninstall: false`）——升级与重装都不会丢会话。

如需彻底清除（含历史遗留的 `%APPDATA%\codelens-desktop`），执行兜底脚本：

```bash
node desktop/scripts/uninstall-cleanup.cjs
```

或手动删除 `%APPDATA%\CodeLens`（及可能存在的 `%APPDATA%\codelens-desktop`）。

## 七、常见问题

**Q1：提示「Windows 已保护你的电脑」（SmartScreen）**
本次构建未使用受信任的商业代码签名证书。点击「更多信息」→「仍要运行」即可继续。
若要对内分发，建议购买代码签名证书后重新构建（删除 `electron-builder.yml` 里对
离线构建的特殊处理即可恢复签名流程）。

**Q2：启动时端口被占用**
应用会启动本地服务端。若默认端口被其它程序占用，请检查日志
（`%APPDATA%\CodeLens\logs\`）确认端口冲突后关闭占用程序。

**Q3：杀毒软件误报**
未签名的 Electron 应用可能被部分杀软误报，将其加入白名单即可。

**Q4：如何确认安装包没损坏？**
核对大小与 SHA256 是否与「产物信息」表一致：

```
129,136,484 字节
b0a99a17e1d6f3373ebd57e6d8ad57d59d50b2b9130f72e6e9706e53e68b13a9
```

本机复核命令（Git Bash / PowerShell）：

```bash
stat -c '%s' CodeLens-Setup-2.0.0.exe
sha256sum CodeLens-Setup-2.0.0.exe
```

```powershell
(Get-Item CodeLens-Setup-2.0.0.exe).Length
(Get-FileHash CodeLens-Setup-2.0.0.exe -Algorithm SHA256).Hash.ToLower()
```

> 每次重新打包后必须重新测量并更新本文件：只要打进包里的任何文件变动，
> 安装包大小与 SHA256 都会变，沿用旧值会让「核对是否损坏」这一步永远失败。

## 八、如何重新构建安装包

在仓库根目录执行：

```bash
# 离线构建（推荐：不依赖外网，使用本地 Electron 镜像与预置的 NSIS/winCodeSign 缓存）
node scripts/build-desktop-offline.mjs --skip-app-build

# 全量构建（先构建前后端，再打包）
node scripts/build-desktop.mjs
```

产物输出目录由 `desktop/electron-builder.yml` 的 `directories.output` 决定，
当前配置为 `C:/codelens-build/release`（不在仓库内）。这样配置的原因见该文件注释：
本机云同步/杀软对 Desktop 目录持有文件句柄，会让 electron-builder 解包/重命名
`app.asar` 时报 EBUSY。换到不同机器或不再同步该目录时，可改回相对路径 `release`。

构建完成后，把 `C:/codelens-build/release/CodeLens-Setup-<version>.exe` 复制到
**仓库根目录**下的 `CodeLens-Setup-2.0.0.exe`，方便直接取用。

> 注意：本仓库所在环境启用了批量删除保护，electron-builder 每次构建前会清空
> `C:/codelens-build/release/win-unpacked`（约 666 个文件），可能触发保护而中断。
> 若遇到此情况，先手动清理 `win-unpacked` / `win-unpacked.tmp` 再重新构建。

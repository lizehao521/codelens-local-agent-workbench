# ADR-010: 样式方案采用 Tailwind CSS 4.3.3 + 设计令牌映射，不引入组件库

## Status: Accepted (2026-10-20)

## Background
设计稿（phase1-uiux.md）以 CSS 自定义属性定义完整设计令牌体系（--color-* / --space-* / --text-* / --radius-*），技术底座提及 Tailwind/shadcn 生态。需在架构层钉死样式方案与组件库边界。

## Decision
样式用 Tailwind CSS 4.3.3（Vite 插件 @tailwindcss/vite 4.3.3），设计稿令牌经 Tailwind v4 `@theme` 指令原样映射为工具类，token 名与设计稿一一对应（如 --color-accent → accent 工具类）。组件层：不引入 shadcn/ui 全套，用原生 HTML + Tailwind + Lucide 手写组件；仅复杂交互原语（Dialog / Dropdown / Tooltip）的无障碍实现成本过高时，允许按需引入 Radix 单原语并说明理由。

理由：
1. 设计令牌即 CSS 变量，Tailwind v4 的 @theme 直接吃变量，设计-开发零翻译损耗；设计稿改令牌，全局生效。
2. 产品界面为工作台三栏布局，主体是 div/button/input 组合，组件库边际收益低于其约定成本；手写组件天然满足单文件 ≤ 300 行与单一职责。
3. Tailwind v4 的 Vite 插件无 PostCSS 配置负担，构建快。

## Consequences
正面：令牌单一来源；bundle 只含用到的类；无组件库版本锁定负担。
负面：长类名字符串可读性差（以组件内按语义分组 + 关键组件抽 class 常量化缓解）；Radix 按需引入时会带来第二个依赖源（控制在 3 个原语以内）。

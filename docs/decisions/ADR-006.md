# ADR-006: 会话历史存浏览器 localStorage，MVP 不引入服务端数据库

## Status: Accepted (2026-10-20)

## Background
产品为纯会话级免登录（无账号体系），需要会话历史在刷新后保留。候选：localStorage / IndexedDB / 服务端数据库 + 账号体系。

## Decision
MVP 阶段会话历史存 localStorage，不建数据库、不建用户表。以 zustand 5.0.15 + persist 中间件管理，存储键 `codeagent.sessions.v1`。

容量与淘汰策略（localStorage 约 5MB 上限，硬编码为产品约束）：
1. 最多保留 20 条会话，超出淘汰 updatedAt 最旧的。
2. 单会话最多 100 条消息，超出从头截断。
3. 每次写入前估算序列化体积，超过 4MB 继续淘汰最旧会话直至达标。
4. 捕获 QuotaExceededError：执行淘汰重试一次，仍失败则提示用户导出历史。
5. 流式更新期间不逐 token 写盘，仅在流结束/停止时写一次（防主线程阻塞）。

跨设备同步需求登记为 OPEN-DECISION OD-1：待真实诉求出现，再引入 PostgreSQL + 轻量账号体系，并新增 ADR 修订架构文档。

## Consequences
正面：零后端存储成本；无账号体系的产品复杂度；隐私叙事干净（数据不出浏览器，BYOK 模式下 Key 也不出浏览器）。
负面：清浏览器数据即丢历史（设置页提供导出/导入 JSON 缓解）；5MB 容量天花板；无跨设备。

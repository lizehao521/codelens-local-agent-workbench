# ADR-004: 锁定 Lucide React 1.60.0 为全项目唯一 SVG 图标库

## Status: Accepted (2026-10-20)

## Background
团队级 P0 绝对规则：架构与 API 文档禁用 emoji；必须锁定一套 SVG 图标库，全项目统一不混用。候选：Lucide React、Heroicons、Tabler Icons、React Icons。

## Decision
锁定 Lucide React 1.60.0（npm latest，核实日 2026-10-20）。所有功能图标（按钮、状态、导航、空态）一律从 `lucide-react` 按名导入，如 `import { MessageSquare, Play, Settings } from 'lucide-react'`。禁止 import * 全量导入；禁止 emoji 充当图标；禁止引入任何第二套图标库。

理由：
1. 树摇完善：按名导入后仅打包用到的图标（单个 < 1KB），全集才约 30KB。
2. 风格统一：严格设计规则（24px 网格、2px 描边），与"清晰排版"的产品要求匹配；1900+ 图标覆盖工具类应用细粒度场景（Heroicons 约 300 个偏少）。
3. React Icons 是多库合集，天然导致风格混用，违反 P0 规则；Tabler 数量冗余偏仪表盘风。

## Consequences
正面：bundle 可控；设计-开发图标命名可一一对齐（设计标注用 Lucide 名）。
负面：与 Tailwind 官方 Heroicons 生态的示例代码不兼容（本项目用 Tailwind 工具类但不依赖其图标示例）——可忽略。

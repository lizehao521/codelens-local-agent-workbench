# ADR-002: 使用 CodeMirror 6（@uiw/react-codemirror 4.25.12）作为代码编辑器

## Status: Accepted (2026-10-20)

## Background
产品核心界面之一是代码编辑区，用户在此粘贴/编辑代码片段。候选：CodeMirror 6、Monaco Editor、Ace。产品要求响应式设计（移动端可用）与快速首屏。

## Decision
选择 CodeMirror 6，经 @uiw/react-codemirror 4.25.12 接入 React。按需安装语言包：@codemirror/lang-javascript 6.2.5、@codemirror/lang-python、@codemirror/lang-json、@codemirror/lang-html、@codemirror/lang-css；主题 @codemirror/theme-one-dark + 自定义亮色主题。

理由：
1. Monaco Editor 官方文档明确声明不支持移动浏览器，与响应式硬约束冲突，一票否决。
2. 体积：CM6 核心约 40-200KB gzip（按语言包裁剪），Monaco 约 2.4MB；首屏 < 2s 目标下差距决定性。Replit 公开披露从 Monaco 迁移至 CM6，理由即移动端与包体积。
3. 模块化扩展体系（Lezer 解析器）对本场景（高亮 + 行号 + 基础编辑）恰好够用，无需 IDE 级补全。

## Consequences
正面：移动端原生触摸可用；bundle 小；主题可完全自定义（与设计规范对齐）。
负面：无内置 TS/JS 语言服务（无类型补全/错误波浪线）——MVP 不需要，登记为已知取舍；CM6 命令式 API 与 React 有阻抗，须用 useRef/useEffect 薄封装，禁止重渲染驱动编辑器状态。

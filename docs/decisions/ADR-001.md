# ADR-001: 使用 React 19.3.1 + Vite 8.3.4 SPA 作为前端方案

## Status: Accepted (2026-10-20)

## Background
产品为工具型 Web 应用（编程 Agent），用户方向已确认 React + TypeScript。需要在前端框架形态上做决策：SPA（Vite）还是 SSR 元框架（Next.js/Remix）。本项目无 SEO 需求、无内容索引需求、纯交互工具。

## Decision
选择 React 19.3.1 + Vite 8.3.4 构建的纯客户端 SPA，TypeScript ~5.9，不引入 Next.js/Remix。

理由：
1. 无 SEO 需求，SSR 的核心收益不存在，引入 RSC/服务端组件心智是纯负担。
2. 构建产物为静态文件，可由后端 Express 同端口托管，前后端同源，免 CORS、免双部署。
3. Vite 的 dev server HMR 与构建速度直接提升 MVP 迭代速度。
4. React 19 是当前稳定主线（npm latest 19.3.1，核实日 2026-10-20），zustand 5.0.15、@uiw/react-codemirror 4.25.12 等核心依赖均兼容。

## Consequences
正面：部署形态最简单（一个容器一个端口）；无服务端渲染的 Node 常驻成本；前端可完全静态 CDN 化（未来若分离部署）。
负面：首屏需等 JS  bundle（以 lazy + gzip +  CDN 控制在 2s 内）；无 SSR 的元标签控制（本项目不需要）；后续若产生 SEO 需求（如公开分享页）需重新评估。

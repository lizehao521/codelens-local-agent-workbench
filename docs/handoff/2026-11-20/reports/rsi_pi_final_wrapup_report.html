  • 丁对真实代际的覆盖率增量目前是 0：CHECKPOINT_ENABLED 默认关闭，必须部署方显式开启才生效。

五、exp172 裁定要点（只读入口）

做，但只做只读。 三条红线：
① 不补采历史代——给旧代补写 created_at/updated_at/origin 等于伪造「当时已采」，会改分母与状态比例，本轮一律禁止；
② 不折叠状态——complete / partial / unavailable / not_attempted 必须可区分，不能靠「没返回 diffText」推断 unavailable；
③ 不动旧语义——loadGenerationDiff 仍只给 INV-1 可消费的完整正文，collectDiffEvidence 签名不变，两者零行为变化。
实现取更严形态：ReadbackDb 只声明 get/all，写库在类型层不可达；非法 status/origin/盲区 JSON 一律抛错。

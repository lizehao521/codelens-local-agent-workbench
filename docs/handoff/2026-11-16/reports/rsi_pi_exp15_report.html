四、有一条我判错了：P3

P3 的结论是「原行为正确，不改代码」。我给它的题面写的是「跳过不是绿」，但视图 workspace/.runtime_view/src 在 .gitignore 第 27、76 行，不进版本库；CI 是干净 checkout，必然没有这个目录。改成 exit 2 只会把「恒绿的门禁」换成「恒红的门禁」——test:acceptance 是 && 链，ci.yml 里没有任何退出码映射。

所以正确语义是它第 2 投给出的那个：默认路径缺失 = exit 0 跳过（stderr 留痕）；显式 --view 缺失 = exit 2。门禁的真实价值在本地/运行期（视图已生成时逐文件比对），不在 CI。这一条我不再算缺口，如实记下。

残余风险仍在：跳过时 CI 日志里只有一行 stderr，没有「未校验」的显式标记；如果哪天视图在生产机上被删成空目录，会被判成「全部 missing」而 exit 1——这个是能抓到的，反倒是安全的。

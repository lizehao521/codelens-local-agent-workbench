**冲突优先级（写死，从高到低）**

| 级 | 规则 |
|---|---|
| P0 | **S00 元层先判**：任何输入先过 S00，产出槽位 ID 后才允许执行；`chosen` 可等于 `S01`。 |

**升级到人的条件（任一命中即停并交人，S00 在《路由判定》里写明）**

1. 涉及人所有目录改动：`tests/`、`judge/`、`krsi/`、`rsi/`、`eval/`、`scripts/`、`self-upgrade/`（AGENTS §2）→ `attribution=human` + 重锚 `.self-upgrade/baseline.json`。
2. 需要 `promote`：判据草稿回 `tests/self-upgrade/`、采纳落 D4。
3. 自动采纳越过 D1 或 >6 文件；`promote` 与重锚顺序可能被颠倒。
4. 高危写：`fs.write` 覆盖 / 删除 / 清空需用户确认；回滚需头 `x-codelens-confirm: rollback`（能力未开 409 / 缺头 400）。
5. 越界授权审批走 `[端点] POST /api/v1/sandbox-grants/:id/decision`（请求体字段 **W7 待核实**）。
6. 无证据却要宣称「可复现真回归」→ 打 `REGRESSION_VERDICT=unexec` 并归 infra，交人。
7. 出口链路 / 上游封锁需决定重试时机（`halt_manual` / `raise_budget`）、或需重启 8080 旧实例。
8. 输入要求跨槽位越权、或同时命中 S00 与改动类动作且无法拆分。

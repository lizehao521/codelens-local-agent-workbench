# 知识总结

> 一句话：逐份精读、逐章节摘要、出处即章节号、冲突并列保留。

## 何时使用

- 需要把多份长资料压缩成可快速检索的摘要。
- 需要为后续分析/设计提供"可回到原文"的中间产物。
- 需要交叉比对多份资料，暴露矛盾与缺口。

## 执行流程

1. **盘点资料** —— 建资料清单，标注类型与解析状态（失败/跳过注明原因）。
2. **逐份精读** —— 按每份资料自身章节结构逐条摘要，不跨文档归并。
3. **出处即章节号** —— 每条摘要标注 `编号，§章节`，可一键回原文。
4. **费曼自检** —— 摘要用自己的话重述，确保真的理解了而非照抄。
5. **冲突与缺失记录** —— 矛盾并列保留两个版本 + 出处；缺口单独列"待确认项"。
6. **硬指标自检** —— 逐项核验收口标准，产出最终摘要。

## 输入 / 输出

| 输入 | 输出 |
| --- | --- |
| 原始资料（多份、多格式） | 逐份逐章节摘要 |
| 摘要口径/验收标准 | 冲突记录 + 缺失项 |
| — | 可回溯出处映射 |

## 关联思维策略

- **SQ3R** —— 浏览→提问→精读→复述→回顾。
- **费曼技巧** —— 用重述检验理解深度。
- **康奈尔笔记** —— 主区摘要 + 边栏要点 + 底部总结。
- **思维导图** —— 先摸清整体结构再逐章节深入。

## 基因库记录

- **类型**：lesson
- **复用经验**：摘要按原文自身结构组织、不做跨文档归并；出处必须可回溯；冲突不裁决、缺失单独列。
- **可复用性**：高 —— 读完资料做摘要的通用流程。
- **入库自检**：用户选择 ✅ / 适应度前 100 ✅ / 可复用 ✅

## 示例

### 场景：把一份 SKILL.md 精读成资料摘要

1. 盘点：1 份资料（SKILL.md，Markdown 已解析）。
2. 精读：按 11 个章节逐条摘要，标 `D1，§1..§11`。
3. 冲突：识别策略总数 26 vs 25 矛盾，并列保留 X1/X2。
4. 缺失：结晶化机制、性能指标等 6 项单独列出。
5. 验收：硬指标 3 项全过，交付摘要文档。

## 安全与回滚

- **透明**：区分"直接引用 / 数据提取 / 综合归纳"。
- **可控**：只读不写原始资料。
- **可逆**：摘要版本化，可重跑重生成。
- **渐进**：先摘要再比对，不一步到位。
- **用户主导**：冲突裁决与口径由用户拍板。

## 工具对齐（当前异结构工具面）

弱对齐：glob/grep/read 定位与读取素材；核心仍是逐份精读摘要（推理），无确定性工具。

# 数据可视化

> 图表是给"结论"配的证据，不是给数据配的装饰。

## 何时使用

- 需要向受众传达数据背后的结论。
- 做个周期性报表 / 趋势 / 对比。
- 把一堆数字变成一眼可读的东西。

## 执行流程

1. **明确结论与受众** —— 一句话：想让对方看懂什么。
2. **选图表类型** —— 趋势用折线、占比用饼/条、对比用柱、分布用直方。
3. **清洗与聚合** —— 去噪、对齐口径、聚到合适粒度。
4. **生成 / 渲染图表** —— 用库产出，控制颜色与坐标。
5. **加标注** —— 标题点结论、坐标轴带单位、关键点加注释。
6. **校验可读性** —— 换人看一遍：能否 5 秒读懂结论。

## 输入 / 输出

| 输入 | 输出 |
| --- | --- |
| 原始数据 | 图表 + 结论标注 |
| 目标结论与受众 | 图表类型选择 |
| 数据口径 | 清洗后数据 |

## 关联思维策略

- **对比分析** —— 用对比基线让差异显形。
- **思维导图** —— 先梳理"要讲哪几层结论"再选图。

## 基因库记录

- **类型**：pattern
- **复用经验**：先问结论再选图；一图一个结论，不堆指标；坐标轴必须有单位。
- **入库自检**：用户选择 ✅ / 适应度前100 ✅ / 可复用 ✅

## 示例

周报营收 → 结论"本周环比 +12%" → 选折线看趋势 + 柱状看环比 → 标题直接写结论。

## 安全与回滚

- **透明 / 可控 / 可逆 / 渐进 / 用户主导**：数据口径与结论措辞由用户确认。

## 工具对齐（当前异结构工具面）

无对应确定性工具（图表需渲染后端，偏重）。输出用结构化数据交给渲染端；候选：图表生成器插件。当前纯方法论。
